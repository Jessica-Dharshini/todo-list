# To-Do List App

A simple command-line to-do list written in Python. Tasks are saved to a
`tasks.json` file, so they are still there when you run the app again.

## Features

- Add new tasks
- View all tasks with their status
- Mark tasks as done
- Delete tasks
- Automatic saving

## Requirements

- Python 3.6 or newer (no extra libraries needed)

## How to Run

```bash
python todo.py
```

On some systems use `python3 todo.py`.

## Example

```
===== TO-DO LIST =====
1. View tasks
2. Add a task
3. Mark a task as done
4. Delete a task
5. Exit
Choose an option (1-5): 1

Your tasks:
  1. [x] Buy groceries
  2. [ ] Finish Python project
```
